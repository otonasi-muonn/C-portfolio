# Strategic Compact (C-portfolio)

## 使う場面

- 調査 -> 実装 のフェーズ切替時
- 大きな修正を終えて次タスクへ移る時
- 会話履歴が長くなり、応答精度低下を感じる時

## 推奨タイミング

- 設計調査完了直後
- 実装完了直後（検証前後）
- 無関係タスクへ切り替える直前

## 注意

- 実装途中（未保存の判断材料が多い状態）ではcompactしない
- compact前に、必要情報は `docs/` や作業ファイルへ明示的に残す
